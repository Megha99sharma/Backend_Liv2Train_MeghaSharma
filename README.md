# Training Center Registry API

Backend assignment created using ASP.NET Core Web API.

## Features
- Create Training Center API
- Get Training Centers API
- Validation using Data Annotations
- Exception handling
- Swagger integration
- SQL Server support

## APIs

### Create Training Center
POST /api/trainingcenter

### Get Training Centers
GET /api/trainingcenter

## Tech Stack
- ASP.NET Core 8
- Entity Framework Core
- SQL Server
- Swagger

## Run Project
1. Open solution in Visual Studio
2. Run migration
3. Start project
4. Open Swagger
